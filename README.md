# Rice Leaf Disease Detection and Solutions Recommendation System

## Overview
This project detects rice leaf diseases using Convolutional Neural Network (CNN) and provides solution recommendations for farmers.

## Technologies Used
- Python
- Django
- CNN
- OpenCV
- TensorFlow/Keras
- MySQL

## Features
- Detects rice leaf diseases
- Identifies healthy and unhealthy leaves
- Non-rice leaf validation
- Provides chemical solutions
- Suggests water management advice

## Diseases Detected
- Brown Spot
- Leaf Blast
- Leaf Blight
- Healthy Leaf

## Future Scope
- Mobile application support
- Real-time camera detection
- More disease classes
- IoT integration
